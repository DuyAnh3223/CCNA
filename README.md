# CCNA Packet Tracer Labs

A collection of daily networking labs built with **Cisco Packet Tracer** as part of my CCNA learning journey. Each day focuses on a different topic, turning networking theory into hands-on practice.

## Repository Structure

Labs are organized into numbered folders by day: `01/`, `02/`, `03/`, and so on. Each folder contains the files relevant to that day's exercise:

- **README.md** - objectives, instructions, and learning notes.
- **Packet Tracer file (`.pkt`)** - the network topology and any saved configurations.
- **Topology screenshots** - a visual reference for the lab.
- **Additional notes or configuration files** - included when needed.

## Lab Index

| Day                | Topic                      | Practice                                                                                                   |
| ------------------ | -------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [01](01/README.md) | Packet Tracer Introduction | Place and label network devices, recreate a topology, and connect devices using automatic cable selection. |
| [02](02/README.md) | Connecting Devices | Manually select straight-through, cross-over, and fiber cables with Auto MDI-X disabled; choose single-mode or multimode fiber based on distance. |

New labs will be added as I progress through the material.

## Getting Started

1. Install Cisco Packet Tracer.
2. Clone or download this repository.
3. Open a day's folder and read its `README.md`.
4. Open the `.pkt` file in Packet Tracer to explore the saved lab, or recreate the topology yourself using the instructions.
5. For configuration exercises, follow the verification steps documented in that lab.

## Learning Goals

- Understand the roles of network devices and how they connect.
- Apply networking concepts through practical exercises.
- Build configuration and troubleshooting skills as new topics are introduced.
- Keep a record of lab work, observations, and lessons learned.

The scope and verification results are documented separately for each lab. Early exercises may focus only on building a topology; later exercises may include device configuration and connectivity testing.
